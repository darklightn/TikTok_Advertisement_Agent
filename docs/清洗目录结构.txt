这里增加三个非常有用的计算列：

```

```

例如：

```

```

即使ROI暂时还能看，也可以迅速发现：

> 这个素材正在吃掉过多预算，但贡献不足。

素材的付费曝光、点击、广告转化率以及2秒到100%视频播放率，都属于当前 Product GMV Max 官方素材报告指标。

注意这里我没有放：

```
钩子类型
核心卖点
使用场景
CTA
```

这些以后应该从你的AI带货视频系统通过 Post ID / Video ID 接进来，而不是广告数据清洗阶段自己创造。

# 4、商品经营诊断.xlsx
这一张不是重新分析广告。

它回答：

> 广告已经把流量送过来了，商品本身有没有能力把流量接住。

一行代表：

> 一个商品在一个统计区间的经营表现。

本表商品行集合由以下三类商品取并集：

```
统计区间内商品分析表现中的商品
+
统计区间内 GMV Max 计划商品表现中的商品
+
最新 products 快照中的当前可售商品
```

因此，当前可售但本区间没有销售/广告表现的商品仍保留；历史区间有表现、但当前已下架或删除的商品也仍保留。没有区间记录不等于指标为0，无法证明为0的区间指标保持空值。

表头：

```

SKU总数

缺货SKU数
低库存SKU数

总库存

广告币种
成本币种
```

这里有几个字段命名非常重要。

不要叫：

```
CVR
```

统一叫：

```
CTOR
```

因为 TikTok 当前 Product Analytics 已把旧的 Conversion Rate 统一改名为 CTOR，即 Product clicks → SKU orders。官方同时提供 Product impressions、Product clicks、CTR、Add-to-cart count/rate 等漏斗指标。

利润相关只保留：

```
估算商品毛利率
保本ROI
ROI安全差
```

暂时不造一个所谓“精确净利润”。

因为你当前人工成本表已经足够支持“广告还能不能继续跑”的主要判断。

例如：

```
保本ROI = 1.80
实际ROI = 2.40

ROI安全差 = +0.60
```

比只告诉投手“ROI 2.4”有用得多。
