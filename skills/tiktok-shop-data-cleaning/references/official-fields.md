# 官方字段直取规则

以下字段从同业务语义、同粒度、同统计区间的原始数据读取。金额及数值字符串使用现有数值标准化；`-`、N/A、空字符串等保留为空，不用公式补值。官方零值保留为零。

| 清洗表 | 清洗字段 | 原始来源与字段 | 格式 |
| --- | --- | --- | --- |
| 广告户诊断 | GMV Max平均下单成本 | GMV Max 计划总览唯一官方总计行：Cost per order (Current shop) | 数值 |
| 广告户诊断 | 实际ROI | 同一总计行：ROI (Current shop) | 数值 |
| 计划诊断 | 广告CTR | GMV Max 计划表现：ctr | 百分数值除以100，如3.50→0.035 |
| 计划诊断 | GMV Max平均下单成本 | 同计划表现：cost_per_onsite_roi2_shopping_sku | 数值 |
| 计划诊断 | 实际ROI | 同计划表现：onsite_roi2_shopping | 数值 |
| 计划小时表现 | GMV Max平均下单成本 | GMV Max 计划小时表现：cost_per_order_official | 数值 |
| 计划小时表现 | 实际ROI | 同小时表现：roi_official | 数值 |
| 素材诊断 | GMV Max平均下单成本 | GMV Max 计划商品素材表现：平均下单成本 | 数值 |
| 素材诊断 | 商品广告点击率 | 同素材表现：Product ad click rate | 原始底层已为0～1小数，直接读取 |
| 商品经营诊断 | AOV | 商品分析表现：全部.平均订单金额（SKU 订单） | 金额数值 |
| 商品经营诊断 | 商品点击率 | 商品分析表现：全部.商品点击率 | 带%文本转0～1小数 |
| 商品经营诊断 | 加购率 | 商品分析表现：全部.加购率 | 带%文本转0～1小数 |
| 商品经营诊断 | CTOR | 商品分析表现：全部.CTOR（SKU 订单） | 带%文本转0～1小数 |
| 店铺诊断 | 实际ROI | GMV Max 计划总览，与成本、订单、收入相同的唯一官方总计行：ROI (Current shop) | 数值 |
| 营销活动明细 | 营销活动ROI | 营销活动表现：ROI | 数值 |

GMV Max 计划总览的总计标记为时间或按天列中的 `-`；总计缺失或重复时失败，不汇总明细替代。

商品经营诊断的广告成本、订单、收入先跨计划汇总，平均下单成本和实际ROI继续用汇总后的基础量计算；不能平均或任选计划商品的官方比率。店铺诊断的AOV、点击率、加购率、CTOR继续按店铺汇总基础量计算，不能使用单个商品比率或平均商品比率。店铺订单数和客户数保持现有订单明细口径。

日均指标、CPC、CPM、小时及广告户CTR、素材ROI、跨计划/商品/素材汇总、占比、退款比例、利润、风险、状态等其他派生规则保持各自现有计算。本规则不引入新导出报表。
