# 输出文件核验

多表清洗完成后，对每个 CLI 成功结果执行以下核验：

1. 确认输出路径对应的 `.xlsx` 文件存在。
2. 用 Excel 读取库打开文件，确认至少有预期工作表（通常为 `数据`）。
3. 读取首行确认表头非空，并记录列数或关键字段。
4. 从第二行开始计数，记录实际数据行数；将其与 CLI 返回的 `rows` 对比。
5. `rows: 0` 且文件存在、表头正常时，应报告为成功的零行结果，而不是失败。
6. 若读取失败、工作表缺失或表头为空，应将核验标记为失败，即使 CLI 返回 success，也不要声称任务完整成功。

报告时同时列出：表名、范围规则（指定日期范围或最新快照）、实际数据行数、输出路径和核验结论。
