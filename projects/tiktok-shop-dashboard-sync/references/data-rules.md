# 数据规则

## 来源与上传版本

从来源根目录的店铺直接子目录读取以下文件，工作表均为“数据”，第一行为表头：

| 来源 | 相对店铺目录的路径 |
|---|---|
| 店铺经营 | `20_清洗数据/店铺诊断.xlsx` |
| 广告表现 | `20_清洗数据/广告户诊断.xlsx` |
| 商品经营 | `20_清洗数据/商品经营诊断.xlsx` |

必需表头以 `config/boss_table.yaml` 的 `sources` 为准。按列名定位，额外列忽略；重复必需列或缺列阻止该店。全空行跳过，部分缺值行保留并按字段规则处理。

只读所选店铺上游状态目录中的 `Vxxx.json` 分卷，精确匹配 `tables[].local_path`，要求唯一映射、非空 `table_id` 和合法 SHA-256。不额外要求 `status` 或 `state_version`，不导入上游模块、不读取其他报表、不按同名文件回退。映射缺失、冲突或 Hash 不匹配阻止该店。

每份文件只读取一份 bytes 快照，计算 SHA-256 与映射比较，再用 BytesIO 解析同一内容。通过 Hash 核对的快照登记到候选 `source_files`；后续业务错误不抹去已完成的 Hash 核对。这只证明本地快照与上传登记一致，不证明远端来源表的当前内容完整。

## 26 字段

`config/boss_table.yaml` 为字段与指标的可执行声明。每条候选包含全部 26 字段，不适用字段显式为 null。

| 字段组 | 字段 | 类型与适用范围 |
|---|---|---|
| 公共身份与区间（10） | 记录唯一键、记录类型、店铺ID、店铺名称、统计开始日期、统计结束日期、统计区间、店铺币种、广告币种、数据更新时间 | 两种记录共用；唯一键为文本主字段，记录类型为单选，起止日期为日期，更新时间为带时区时间，其余为文本；币种可按下述规则为空，其他公共字段必填 |
| 店铺指标（10） | GMV、订单数、客户数、AOV、退款金额率、广告消耗、广告收入、实际ROI、广告订单、平均下单成本 | 数值，仅店铺汇总适用，可为空 |
| 商品身份（2） | 商品ID、商品名称 | 文本，仅商品结果适用；商品ID必填，名称可为空 |
| 商品指标（4） | 商品GMV、商品订单数、商品实际ROI、商品退款金额率 | 数值，仅商品结果适用，可为空 |

记录类型仅为“店铺汇总”或“商品结果”。店铺ID、广告户ID、商品ID须为非空文本，保留长 ID 和前导 0，拒绝数字 ID。

## 空值、数字与币种

清洗结果为空及不适用字段均为 null，真实零保留；不根据其他字段推断或改写最终值。数字接受数值和数字文本，拒绝布尔、不可解析及非有限值；计数须为整数。比率不乘 100，不限制在 0 到 1。业务日期按来源当天处理，不转 UTC 导致日期偏移。

经营币种为 PHP，广告币种为 USD，每次构建检查参与行。店铺GMV或AOV有值（包括明确的零）时，店铺币种必需；广告总成本、GMV Max总收入或GMV Max平均下单成本有值时，广告币种必需。商品GMV有值时，店铺币种必需；商品广告币种允许为空，非空必须为USD，不依赖商品广告成本或收入列。不做汇率换算，不改写全局币种标签。

任一参与行币种不符或金额有值但缺币种，阻止该店本轮全部候选，其他店铺可继续。未选日期的正常业务行不参与数值和币种检查；文件结构错误与无法归属区间的身份错误仍报告。

## 完整区间与唯一键

只匹配同一完整起止区间，不拼接、不推断缺失区间。三份来源均无匹配区间为 `NO_DATA`；部分缺失为 `PERIOD_INCOMPLETE`。同来源同区间身份键重复不求和，多个广告户未经业务确认不相加。

店铺名称冲突、同 ID 跨目录或不同 ID 同展示名阻止冲突目录。无法归属区间的身份错误阻止店铺；可定位到区间的错误阻止该区间，其他完整区间可继续。

唯一键格式：

```text
店铺汇总|{shop_id}|{start_date}|{end_date}
商品结果|{shop_id}|{start_date}|{end_date}|{product_id}
```

键中的日期使用 `YYYY-MM-DD`。区间标签单日直接使用日期，多日以“ ～ ”连接起止日期。同名不同 ID 商品分别保留，不按商品名称分组。

## 同步、改名与保留

同步发现已确认的同一店铺ID发生改名时，统一更新该店铺所有受管历史记录的店铺名称，业务数据和唯一键保持不变。若该店铺是老板看板已保存的默认店铺，则由Agent修复店铺切片器的已保存默认名称，默认统计区间保持不变。

当前店名只取自通过来源版本、币种、ID 与名称核验的候选，不按目录名重新分配店铺 ID，不在来源全受阻时单独执行改名。改名操作本身不改业务值；本轮候选的正常业务更新仍按来源执行。候选范围外的受管历史行只更新店铺名称与数据更新时间，保留 `record_id` 和额外字段。新名称被不同 ID 占用时阻止该店并报告 `TARGET_SHOP_NAME_CONFLICT`，其他有效店铺可继续。

只新增、更新或跳过，不自动删除商品、缺席历史记录或人工行。值变为空时清空旧字段。比较业务内容时忽略数据更新时间，数值使用 `1e-12` 相对与绝对容差，不按页面显示位数取整。候选更新时间是带时区的拟写入时间；远端时间只在实际新增或变化时更新。

## 页面数据口径

10 张汇总卡固定筛选“记录类型=店铺汇总”，在单店、单区间下用 SUM 读取唯一汇总行。商品表固定筛选“记录类型=商品结果”，按商品 GMV 降序逐条展示六字段。

店铺与区间均为单选。清空筛选后的合计不作为经营结果。无匹配数据或指标为空时，允许卡片显示 0，但不能据此将底表 null 改成零。首次默认区间的选择和后续默认值维护见[执行规则](execution-rules.md)，网页操作见[网页操作规则](browser-setup.md)。
